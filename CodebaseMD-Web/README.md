# CodebaseMD web prototype

This directory contains the concept notes for a separate web conversion application. It is **not shipped with the CodebaseMD VS Code extension** and is not part of the v3.0.0 release.

The proposed application would use [Microsoft MarkItDown](https://github.com/microsoft/markitdown) to convert document formats through a web interface. Previous notes described a Next.js frontend, a FastAPI backend, and optional image-description integrations; these are plans, not released extension features.

For the maintained extension, installation instructions, supported source files and privacy behavior, see the [main README](../README.md). The extension exports code context locally and does not provide PDF/Office conversion, OCR, or Gemini integration.
