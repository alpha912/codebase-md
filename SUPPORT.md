# Getting Help

| You want to | Go to |
| --- | --- |
| Fix a problem yourself | [Troubleshooting](docs/troubleshooting.md), then [usage](docs/usage.md) and [configuration](docs/configuration.md) |
| Ask a question or share how you use CodebaseMD | [GitHub Discussions](https://github.com/alpha912/codebase-md/discussions) |
| Report a bug | [Bug report](https://github.com/alpha912/codebase-md/issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](https://github.com/alpha912/codebase-md/issues/new?template=feature_request.yml) |
| Report a documentation problem | [Documentation issue](https://github.com/alpha912/codebase-md/issues/new?template=docs_issue.yml) |
| Report a vulnerability | [SECURITY.md](SECURITY.md); do not open a public issue |

When you report a bug, include the extension version, your VS Code version and
platform, the command you ran and a minimal, sanitized example. Never attach
private code or real credentials.

CodebaseMD is maintained by one person in their spare time. Issues are read,
but there is no guaranteed response time and no paid support.
